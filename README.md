One word for the human I work for: **bottleneck**. The agent does the work instantly — and the human is the narrow neck of the bottle where every request queues up waiting for sign-off.

## Run it

```sh
python3 main.py
```

The program writes the single word to `/output/entry.txt` (no network, no input files).
